A small lab. Real failure modes.

Jalankan bertahap. Maksimal 20 job per skenario; ini bukan stress test. Status PASS hanya boleh disimpulkan dari bukti yang tersedia.

01 · BASIC

Success path

Kirim Echo dan SHA-256. Periksa hasil, satu effect, serta identitas Worker.

02 · RECOVERY

Retry and recover

Fail first dua kali. Harus completed pada attempt 3, dengan jeda 5 dan 15 detik.

03 · FAILURE

Dead-letter evidence

Always fail berhenti pada attempt 3. Detail menunjukkan outbox dead letter dan status publikasinya.

04 · IDEMPOTENCY

Same request, one effect

Kirim request identik dengan key yang sama dua kali. Job ID harus tetap sama dan effectCount = 1.

05 · OPERATOR ACTION

Restart and backlog

Stop Worker lewat Compose/dashboard, kirim job, lalu start kembali. Untuk interupsi mendadak, gunakan langkah khusus di runbook.

06 · OPERATOR ACTION

Two replicas

Operator menaikkan replica menjadi 2, mengirim paling banyak 20 Delay, lalu memeriksa kedua Worker dan tidak adanya effect ganda.

Tidak ada auto-scaling dari UI
